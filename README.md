# 🧮 Calculator Web Application

A simple calculator with a modern dark-themed UI, built using HTML, CSS, and JavaScript.

## ✨ Features
- Addition, subtraction, multiplication, and division
- Percentage and decimal calculations
- Clear (AC) and delete (DE) buttons
- Keyboard support

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript

## 💻 How to Run
Open `index.html` in your web browser.
